Лабораторная 5 — Протокол связной временной метки (Трент–Алиса)

В этой работе реализован «протокол связи». Цель — получить для документа Алисы метку времени так, чтобы она была «зажата» между другими метками, выданными Трентом, и это можно было публично проверить по подписанной цепочке.

Основные идеи реализации:

- Трент присваивает запросам монотонный номер `n` и фиксирует время.
- Для запроса пользователя `A` с хэшем документа `H_n` Трент возвращает подписанный токен `T_n`, содержащий:
  - `n`, `time`, `requester`, `doc_hash`.
  - ссылку на предыдущий токен (его краткое содержание) и накопительную «связь» `link_hash` по правилу: `L_n = H(n || A || H_n || time || L_{n-1})`, где `L_0` — 32 байта нулей.
  - подпись Трента `S_K` над каноничным JSON токена (чистый Python, внешние библиотеки не используются).
- Когда появляется следующий токен `T_{n+1}`, Трент запоминает, кто его запросил, и по запросу сообщает для `T_n` идентификатор следующего отправителя (`NEIGHBOR`). Это моделирует пункт «Трент позже сообщает Алисе отправителя следующего документа».

Файлы:

- `protocol.py` — минимальный RSA (генерация/подпись/проверка), SHA‑256 и каноничный JSON; модель токена.
- `server.py` — сервер Трента (TCP, JSON по одной строке). Хранит цепочку и подписывает токены.
- `client.py` — клиент Алисы: запрос метки, проверка токена, запрос «соседа».

Сообщения протокола (JSON‑объект в строке):

- `STAMP {name, doc_hash}` → `STAMPED {token, signature, pubkey}`
- `VERIFY {token, signature, pubkey}` → `VERIFIED {valid, reason?}`
- `GET {n}` → `GOT {token}`
- `NEIGHBOR {n}` → `NEIGHBOR {n, next_requester?}`
- `PUBKEY {}` → `PUBKEY {n, e}` (публичный ключ Трента)

Запуск и использование:

1) Запустить Трента: `python3 lab5/server.py --host 127.0.0.1 --port 13000`
2) Поставить метку для файла: `python3 lab5/client.py stamp --host 127.0.0.1 --port 13000 --name Alice --file path/to/doc.pdf`
   - или для текста: `--text "hello"`
3) Проверить сохранённый токен: `python3 lab5/client.py verify --token token.json`
4) Узнать, кто пришёл следом за токеном `n`: `python3 lab5/client.py neighbor --n 12`

Примечания:

- RSA реализован в учебном виде (подпись = H(m)^d mod n) — использовать только для лабораторной.
- «Связность» обеспечивается включением `prev_summary` и `link_hash` в каждый токен. Любой может проверить подпись токена по открытому ключу Трента и сопоставить его положение в цепочке через `n` и `next_requester`.
