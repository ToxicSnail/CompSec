# Lab2 — CHAP (RFC 1994)

Учебный проект: идентификация по CHAP (Challenge Handshake Authentication Protocol, RFC 1994) на основе MD5. Сервер проверяет знание общей секрета без его раскрытия по сети: клиент получает случайный челлендж и отправляет отклик MD5(ID || secret || challenge).

Внимание: для учебных целей секрет хранится на сервере в открытом виде в файле `chap_users.json`. В реальных системах так делать нельзя.

## Состав проекта

- `chap.py` — ядро CHAP-MD5: генерация челленджа, расчёт отклика MD5(ID || secret || challenge), конвертеры hex ⇄ bytes.
- `server.py` — TCP‑сервер c командами: `CHALLENGE`, `AUTH`, `STATUS`, `LIST`, `HELP`. Управляет «ожидающими» челленджами с TTL.
- `client.py` — клиент: по `id`, `challenge` и локальному секрету считает отклик и выводит в hex.
- `keyinit.py` — офлайн‑инициализация пользователей: записывает секрет в `chap_users.json` без передачи его по сети.

Требования: Python 3.10+, без внешних зависимостей.

## Быстрый старт

1) Инициализируйте пользователя оффлайн (секрет не передаётся по сети):

```
python3 lab2/keyinit.py alice "pass phrase"
```

2) Запустите сервер (порт по умолчанию `12345`):

```
python3 lab2/server.py
```

3) Подключитесь к серверу (`telnet`/`nc`) и получите челлендж:

```
telnet localhost 12345
CHALLENGE alice
# Сервер ответит ID и CHALLENGE (hex)
```

4) На клиенте посчитайте отклик и выполните `AUTH`:

```
python3 lab2/client.py --secret "pass phrase" --id <ID> --challenge <HEX>
# полученный HEX — это response

AUTH alice <ID> <response_hex>
```

Ожидаемое: при верном секрете сервер вернёт `OK`, иначе `FAIL`.

## Команды сервера

- `HELP` — справка по командам.
- `LIST` — список пользователей.
- `STATUS <user>` — есть ли пользователь.
- `CHALLENGE <user> [len]` — создать челлендж (длина необяз., по умолч. 16 байт).
- `AUTH <user> <id> <response_hex>` — проверка отклика на последний выданный челлендж (TTL ~120 c).
- `QUIT` — закрыть соединение.

## Замечания по безопасности

- CHAP-MD5 устарел криптографически; демонстрационный код предназначен только для обучения.
- Секреты хранятся в открытом виде в локальном файле `chap_users.json` рядом с сервером; регулируйте права доступа к файлу.
