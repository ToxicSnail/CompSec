## Цель лабораторной работы

* Реализовать трёхраундовую SPN‑сеть (вариант № 6) с 3‑битовым S‑блоком и P‑перестановкой.
* Изучить метод дифференциального криптоанализа через генерацию пар \\(X, X′ = X⊕ΔA)\\, шифрование и статистический отбор ключевых кандидатов.
* Автоматизировать основные этапы: построение таблицы распределения дифференциалов (DDT), генерирование пар, шифрование, подсчёт кандидатов последних раундов.

## Теоретическая основа

### Структура раунда SPN

1. **XOR-слой:** 9-битное состояние $S$ XOR с 9-битным под‑ключом $K$.
2. **S‑слой:** разбивка $S$ на три 3‑битовых слова $(a_0,a_1,a_2)$, применение нелинейной замены через S‑блок.
3. **P‑слой:** перестановка 9 бит по «колонкам»:

   * новое слово 0 = старшие биты всех трёх слов,
   * новое слово 1 = средние биты,
   * новое слово 2 = младшие биты.

Вариант работы: два полных раунда $(⊕K→S→P)×2$, третий раунд без P, затем финальный XOR («whitening»).

### Дифференциальный криптоанализ

1. **Выбор входной разности** $ΔA$ (9 бит).
2. **Генерация пар:** $(X,X′=X⊕ΔA)$.
3. **Шифрование** обеих и получение $ΔC=Y⊕Y′$ (9 бит).
4. **DDT:** для S‑блока строится таблица $ddt[δ_{in}][δ_{out}]$ – число пар, дающих такой переход.
5. **Построение характеристики:** через DDT и перестановку прослеживается ветвь $ΔA→…→ΔC$ по раундам, множатся вероятности.
6. **Частичная расшифровка:** для последних раундов перебираются кандидаты под‑ключей (по 3 бита на блок), считается число согласующихся пар, определяется топ‑кандидаты.

### Представление состояния

* **9‑битное состояние** хранится как целое 0…511.
* Функции:

  ```python
  split_to_words(state:Int)->(w0,w1,w2)  # 3 слова по 3 бита
  join_words(w0,w1,w2)->Int               # три слова → 9 бит
  ```

### S‑слой и P‑слой

```python
# S‑слой
def s_layer(state):
    w0,w1,w2 = split_to_words(state)
    return join_words(S_BOX[w0], S_BOX[w1], S_BOX[w2])

# P‑слой
def p_layer(state):
    b = [(state>>i)&1 for i in range(9)]
    new0 = (b[8]<<2)|(b[5]<<1)|b[2]
    new1 = (b[7]<<2)|(b[4]<<1)|b[1]
    new2 = (b[6]<<2)|(b[3]<<1)|b[0]
    return join_words(new0,new1,new2)
```

### Функция шифрования

```python
def encrypt(plain:Int, key:Int) -> Int:
    # Раунд 1
    st = plain ^ key
    st = s_layer(st)
    st = p_layer(st)
    # Раунд 2
    st ^= key; st = s_layer(st); st = p_layer(st)
    # Раунд 3 без P
    st ^= key; st = s_layer(st)
    # Финальный XOR
    return st ^ key
```

### Построение DDT

```python
def build_ddt() -> List[List[int]]:
    ddt = [[0]*8 for _ in range(8)]
    for x in range(8):
      for dx in range(8):
        dy = S_BOX[x] ^ S_BOX[x^dx]
        ddt[dx][dy] += 1
    return ddt
```

* **ddt\[dx]\[dy]** – число x, для которых S(x)⊕S(x⊕dx)=dy.
* Выводится в табличном виде (8×8).
