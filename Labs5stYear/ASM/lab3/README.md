# Лабораторная работа 3


## Общая структура 
Лабораторная работа направлена на создание обфуцированного кода.
В моей реализации представленны следуюшие методы обфускации:
1. Code Flattening
2. False Branches
3. Constant Expression

- При том, что сама структура полностью построена вокруг `Flattening`, у нас 21 step.
- `Constant Expression` представлен в виде мат. выражения:
    ```c
    x = dummy ^ (uint32_t)i;
    uint32_t b = x % 8u;
    uint32_t c = (x * x) % 8u;
    if (c == (b * b) % 8u):
    {
        //some code
    }
    ```
    что сводится к решению: `x^2 % 2 == (x % 2)^2 % 2`
- `False Branch` представлен в 18 step, где только один из переходов позволит нам получить валидный ключ.
