# Lab1 — S/KEY One‑Time Passwords (RFC 1760)

Учебный проект: одноразовые пароли по S/KEY (RFC 1760) — хеш‑цепочка на MD5 с «fold64». Используется только словарный формат из 6 слов (hex‑ввод/вывод отключён).

## Состав проекта

- `otp.py` — ядро S/KEY: `f`, `initial_value`, итерации `f^n`, конвертеры 6 слов ⇄ bytes.
- `skey_words.py` — словарь из 2048 слов (для 66‑битового представления: 64 бита + 2 бита чексуммы).
- `server.py` — TCP‑сервер: регистрация (`INIT/INIT_FINAL`), вход (`AUTH`), статус (`STATUS`). Принимает только 6 слов.
- `client.py` — клиент: считает ответ (`v_{n-1}`) и выводит только 6 слов.
- `keyinit.py` — офлайн‑инициализация: сохраняет `v_n` на стороне сервера.

Требования: Python 3.10+, без внешних зависимостей.

## Быстрый старт

1) Запуск сервера:

```
python server.py
```

2) Подключение к серверу (`telnet` или `nc`):

```
telnet localhost 12345
# или
nc localhost 12345
```

## Регистрация через сервер

1) На сервере:

```
INIT alice
```

Получите `REG_ID`, `SEED`, `N`.

2) Локально посчитайте `v_n` как 6 слов и завершите регистрацию:

```
python client.py --secret "pass phrase" --seed SEED --seq N+1
# вывод: 6 слов — это v_n

INIT_FINAL <REG_ID> N <эти_6_слов>
```

## Аутентификация (логин)

1) Узнайте челлендж (`STATUS alice`) → `n SEED`.
2) Посчитайте `v_{n-1}` и отправьте 6 слов серверу:

```
python client.py --secret "pass phrase" --seed SEED --seq n
# вывод: 6 слов

AUTH alice <шесть_слов>
```

## Офлайн‑инициализация (альтернатива)

```
python keyinit.py alice "pass phrase" 10
```

Примечание: путь к файлу пользователей должен совпадать с тем, что использует `server.py` (по умолчанию `skey_users.json` рядом с сервером).
