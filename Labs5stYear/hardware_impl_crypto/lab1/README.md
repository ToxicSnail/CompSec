# ЛР1 — Этап 1: выбор S и P

Ниже зафиксированы произвольные (нетривиальные) подстановка S и перестановка P для 4‑битного входа.
Если хотите — легко заменим значения под ваши.

## 4‑битный S‑box (таблица подстановки)

Новая таблица S (используется в `rtl/ps_transform.sv`):

| Вход (hex) | Выход (hex) |
|---:|---:|
| 0 | C |
| 1 | 5 |
| 2 | 6 |
| 3 | B |
| 4 | 9 |
| 5 | 0 |
| 6 | A |
| 7 | D |
| 8 | 3 |
| 9 | E |
| A | F |
| B | 8 |
| C | 4 |
| D | 7 |
| E | 1 |
| F | 2 |

Примечание: это перестановка значений 0..F (каждое встречается ровно один раз), не тождественная и не «реверс».

## Перестановка бит P (после S)

Обозначим результат подстановки S как `s_out[3:0]`, а окончательный результат — `dout[3:0]`.

Новый порядок P:

- `dout[3] = s_out[1]`
- `dout[2] = s_out[3]`
- `dout[1] = s_out[0]`
- `dout[0] = s_out[2]`

Краткая форма: P = `[1, 3, 0, 2]` (индексы битов `s_out` в порядке формирования `dout[3:0]`).
