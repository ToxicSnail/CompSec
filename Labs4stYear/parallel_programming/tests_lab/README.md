## test2
Передать случайное число из диапозона [0,9] по кругу, начиная с процесса под номером ноль. При том, что каждый процесс должен добавлять к полученному сгенерированному числу свой номер и отправлять дальше. Задачу необходимол решить с использованием point-to-point. В самом конце работы программа должна вернуть на экран с процесса ноль исходное случайное число и полученное в результате обменов число. Все остальные процессы выдают на экран свой номер и переданное им значение.
